# Build the Lever

If the work can be scripted, script it. The deliverable is the lever that
does or proves the work, so a reviewer can rerun it instead of trusting your
word.

**Why:** a one-time manual pass is unverifiable and unrepeatable. A script is
both the work and the evidence, and it compounds: the next run is free.

**The pattern:**

- Migrations, checks, and proofs become scripts in the repo, not chat history.
- The script prints what it found and what it changed, so its output is the
  artifact a reviewer inspects.
- If you are about to do the same edit a third time, the second time was the
  signal to write the lever.
